# Changelog

## [0.2.0](https://github.com/recalcitrantsupplant/sqlib/compare/v0.1.0...v0.2.0) (2026-10-07)


### ⚠ BREAKING CHANGES

* **api:** `/queries/:id/v`, `/query-groups/:id/v`, `/argument-sets/:id/v` and `/benchmark-experiments/:id/v` are now `.../versions`. Deleting a query or query group cascades its versions instead of orphaning them, and is refused while a version is pinned.
* **web:** move group data graphs out of argument sets
* **api:** ArgumentGraphBinding, graphBindings, DataGraph.mintedFrom and graphParameterKey are removed. Stored graph bindings are not migrated.
* arguments[i] is { head: { vars }, results: { bindings } } with no whenEmpty; the runtime renames alignArgumentSets to assignArgumentSets/completeArgumentSets and normalizeUndefBindings to normalizeArguments.
